This is a [Next.js](https://nextjs.org) project for Navimaster, a hair care product catalog website.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Description

Navimaster is a website for selling professional hair care products, including creams, shampoos, conditioners, and other hair treatments. The site features a catalog of products with categories, prices, and quantities.

## Features

- Home page with featured products and categories
- Full catalog with filtering by category
- Responsive design using Tailwind CSS
- Product listings with images, names, prices, and quantities
